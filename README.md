# Bible Lexicon Maker

Utilities for building Bible lexicon data from Bible JSON files and Strong CSV files.

## Setup

```sh
npm install
```

## Scripts

```sh
npm run dev
npm run build
npm run typecheck
npm run lint
npm run format
```

## Data

- `data/bibles/`: Bible translations in JSON format.
- `data/strongs/`: Strong source files in CSV format.
