# Resource Catalog Language

**Artifact catalog**:
The generated, versioned inventory of distributable Resource artifacts.
_Avoid_: Mobile asset, download list

**Catalog entry**:
The immutable integrity and installation metadata for one Resource artifact.
_Avoid_: Download configuration

**Bundled catalog**:
The minimum Artifact catalog shipped with a Bible Strong client release.
_Avoid_: Default cache

**Publication catalog**:
Immutable metadata describing an editorial dataset and its distributable artifacts.
_Avoid_: Runtime state
