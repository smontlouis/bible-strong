A pill filled with `cta`, labelled in `cta-ink` with the `label` style: the one solid element of a view.

Use it once per view, for the action that leaves the page towards the app or the next step. Every other action is a text link in `accent-ink`, underlined in `accent` at 3px offset. Minimum height 40px, horizontal padding 18px, radius `radius-pill`, no shadow and no border. On hover it moves, it does not change colour. The focus ring is 2px of `accent-ink`, 2px away.

The consumer provides the label, a verb phrase in sentence case (“Ouvrir dans l’app”), and the destination. Source: `.resource-cta` in `apps/site/src/resource-pages.css`.
