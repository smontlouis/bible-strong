A pill in `accent-soft` with text in `accent-ink`, set in the `chip` style: one short fact about what the page shows.

Use it for a Strong code, a part of speech, a count, a version. A chip states; it is not a button, unless it opens a list of the thing it names. Padding 4px by 12px, radius `radius-pill`, no border. The key part of the label may be set at weight 600.

The consumer provides the text, a few words at most. Source: `.resource-chip` in `apps/site/src/resource-pages.css`.
