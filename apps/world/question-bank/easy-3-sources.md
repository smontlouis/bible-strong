# Easy batch 3 — research notes

100 additional draft questions, 50 per Testament, FR/EN, IDs 101–150. Earlier batches were not modified.

Read the selected KJV verses using the actual Bible text in the [KJV JSON mirror](https://raw.githubusercontent.com/thiagobodruk/bible/master/json/en_kjv.json). Additional primary-text browser checks included [John 3](https://www.biblegateway.com/passage/?search=Jean+3&version=LSG%3BBDS%3BFSV), [Luke 24](https://www.biblegateway.com/passage/?search=Luc+24&version=LSG%3BKJV%3BESV), [Psalm 105](https://www.biblegateway.com/passage/?search=Psaumes+105&version=LSG%3BBDS%3BNKJV), and [Psalm 136](https://www.biblegateway.com/passage/?search=Psaumes+136%2CPsalm+136&version=LSG%3BNKJV).

Corrections from source review: replaced questions whose Psalm references shift between printed LSG and KJV because of numbered headings; the frogs question now cites Psalm 105:30, avoiding the Exodus 8 numbering difference. Luke 24's food question specifies food obtained by fishing because KJV additionally mentions honeycomb. New-birth aliases accept both “again” and “from above”.

Counts, bilingual fields, ID sequence and fact-key uniqueness were checked across all twelve catalogue files. Candidate semantic duplicates were reviewed with the other authors and replaced where they asked the same fact. Different facts can still share a passage. Per-question URLs are reading links; not every URL was individually opened. These paraphrased questions remain human-review drafts, not independently approved material.
