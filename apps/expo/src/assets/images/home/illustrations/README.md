# Desktop home illustrations

The WebP files are unmodified local copies from `apps/site/public/images/landing/`, bundled by Expo
without introducing a runtime dependency on the public site. Style:
`bible-strong-univers-v1` (see `docs/design/illustrations.md` at the repository root).

- `lexicon-universe.webp`: daily verse hero.
- `audibible-reader.png`: generated listening/reading scene, with an opaque navy background matching the card. See `audibible-reader.md` for the exact prompts and reference.
- `online-library.webp`, `comparisons-universe.webp`, `dictionary-universe-v3.webp`: preserved assets from the earlier editorial exploration, no longer rendered by this dashboard.

The WebP copies retain their source transparency. The final layout reference is
`output/imagegen/expo-web-home-2026-09-10/01-tableau-de-bord.png`.
